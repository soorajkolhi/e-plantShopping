# e-plantShopping

**Project name: e-plantShopping (Paradise Nursery)**

e-plantShopping is the shopping cart application for Paradise Nursery, an online houseplant shop
built with React and Redux Toolkit. Users can browse plants by category, add them to a shopping cart,
change quantities, remove items and see the total cost update live.

## Features
- Landing page with background image, company name and a "Get Started" button
- About Us section describing Paradise Nursery
- 3 plant categories with 6 plants each (thumbnail, name, price)
- "Add to Cart" button (disabled once added) and live cart count in the navbar
- Navbar with Home, Plants and Cart links on both the product and cart pages
- Cart page with per-item subtotal, total amount, +/- quantity buttons, delete,
  Checkout ("Coming Soon") and Continue Shopping

## Tech stack
React, Redux Toolkit, Vite

## Run locally
```
npm install
npm run dev
```
